# AI Usage Log — Drive School

AI was used as a learning and explanation tool during the development of the project.

## Questions Asked

1. How does jQuery work and how is it different from plain JavaScript?
2. How do jQuery selectors and DOM traversal methods work?
3. How can elements be created dynamically with jQuery?
4. How do `.on()` and delegated event handlers work?
5. How can `$(this)` and method chaining be used?
6. How do jQuery effects such as `fadeIn()`, `fadeOut()`, `slideDown()` and `slideUp()` work?
7. How can forms be validated using jQuery?
8. What is the difference between `.attr()` and `.prop()`?
9. How can JavaScript features be rewritten using jQuery?
10. How can jQuery code be tested and checked for console errors?

## Use of AI

AI was used for explanations, debugging guidance and clarification of JavaScript and jQuery concepts. The team reviewed, tested and integrated the final code into the project.

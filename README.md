# Drive School — учебный сайт на HTML

Учебный проект по основам HTML: сайт вымышленной автошколы Drive School, построенный на реальных данных (адрес, цены, расписание, инструкторы) без использования CSS, JavaScript или каких-либо фреймворков.

## Структура файлов
```
/
├── index.html          — главная страница

├── instructors.html    — инструкторы
├── price.html          — категории и цены
├── schedule.html       — расписание занятий
```

## Как открыть сайт
Хостинга нет — сайт представляет собой набор локальных файлов. Скачайте репозиторий и откройте `index.html` в любом браузере; переходы между страницами работают через обычные относительные ссылки.

## Технические особенности
- Чистый семантический HTML5, без CSS и JavaScript.
- Каждая страница проходит проверку [W3C Validator](https://validator.w3.org/) без ошибок.
- `div`/`span` используются только там, где нет подходящего семантического тега, и сопровождаются комментарием с объяснением.
- Формы на сайте пока никуда не отправляют данные (`action="#"`) — это техническое ограничение текущего этапа курса, обработка появится позже в семестре.
